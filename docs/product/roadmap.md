# Roadmap

## Phase 0 - Project operating system

- Define product, UX, and architecture docs
- Define the agent orchestration system
- Build the custom MCP server
- Create the mobile project scaffold

## Phase 1 - MVP foundation

- Auth with email/password
- Local-first trip storage
- Basic trip CRUD
- Geocoding for city selection
- Map rendering with straight-line legs
- Transport-aware leg visualization

## Phase 2 - MVP polish

- Better validation and editing flows
- Saved drafts
- Improved transport icons and labels
- Better empty states and onboarding

## Phase 3 - Post-MVP travel depth

- Map-first stop editing
- Route-aware road and ferry geometry
- More detailed stay data
- Place bookmarks and visit markers

## Phase 4 - Memory layer

- City photo galleries
- Photo pins on the map
- Accommodation markers
- Trip moments and journal overlays
