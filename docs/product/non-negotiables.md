# Non-Negotiables

## Product

- The app is mobile-first.
- The first release is single-user.
- The first release must feel simple to use.
- The travel map is the product centerpiece.

## UX

- Visual direction: clean Mediterranean.
- Primary palette: white and shades of blue.
- Map and itinerary must be understandable without extra explanation.
- Forms should feel close to ticket-booking flows, not admin panels.

## Technical

- Use free/open-source-first tools where practical.
- Do not depend on paid-only APIs or SDKs.
- Keep a migration path from Supabase to a custom backend.
- Keep trip storage local-first for v1.
- Use straight-line route rendering in v1.

## Process

- Build agents first.
- Build the MCP server second.
- Build the mobile app after the MCP tools are usable.
- Keep docs current as architecture evolves.
