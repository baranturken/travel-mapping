# MVP Scope

## In scope

- Mobile-first app foundation
- Account creation and sign-in with email and password
- Trip list for the signed-in user
- Create-trip flow from a simple form
- Add departure, destination, and intermediate stops
- Add transport method for each leg
- Add simple stay details per stop
- Generate a map from the saved trip
- Display straight-line trip legs between stop coordinates
- Display transport icons or labels per leg
- Display a leg-by-leg trip summary

## Out of scope

- Real-time collaboration
- Social sign-in
- Route-aware bus, ferry, train, or car paths
- Accommodation booking integrations
- Photo uploads and galleries
- Geotagged memory pins
- Shareable public trip pages
- Offline account signup

## Delivery principle

Favor a complete, reliable narrow slice over a broad but fragile v1.
