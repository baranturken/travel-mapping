# Product Vision

## Core idea

Travel Mapping turns a planned journey into a visual story on a map. Instead of reading a plain itinerary, the user sees where they start, where they stop, how they move between places, and how the trip flows end to end.

## User problem

Travel planning tools are good at tickets, bookings, and lists, but they are weak at showing the full journey in one mobile-friendly view. Multi-stop trips become mentally heavy fast, especially when they mix buses, ferries, flights, and city stays.

## Primary goal

Help a traveler understand and organize a full trip on a map in a way that feels immediate, visual, and mobile-native.

## Secondary goals

- Make multi-stop trips easier to create than manual note-taking.
- Show transport choices clearly per leg.
- Make the trip feel memorable, not only functional.
- Create a foundation for later travel memories and galleries.

## Target user

The first user is a traveler planning a personal or shared real-world journey with multiple stops. The MVP assumes one person creates and edits the trip, even if the trip itself involves friends.

## Product promise

If a user enters the stops and transport details for a journey, the app should return a clean map view that makes the trip easy to see and easy to explain.
