# Screen Map

## Core screens

1. Welcome / auth
2. Home / trip list
3. Create trip
4. Add or edit stop
5. Add or edit leg details
6. Trip map view
7. Trip summary and edit
8. Profile / settings

## MVP emphasis

The create-trip and trip-map screens are the most important screens in the first release.

## Notes

- Keep auth minimal and fast.
- Keep the trip builder linear.
- Let the map view feel like the reward after entering the itinerary.
