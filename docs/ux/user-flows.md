# User Flows

## Flow 1 - Sign up

1. User opens the app.
2. User sees a simple welcome screen.
3. User creates an account with email and password.
4. User lands on the trip list or home screen.

## Flow 2 - Create a trip

1. User taps create travel.
2. User enters a trip title.
3. User adds the departure city.
4. User adds one or more stops.
5. User adds the final destination.
6. User assigns a transport method to each leg.
7. User optionally adds stay notes per stop.
8. User submits the trip.
9. App saves the itinerary and opens the generated map view.

## Flow 3 - View trip

1. User opens a saved trip.
2. User sees a map with markers and leg lines.
3. User sees the itinerary summary below or beside the map.
4. User can switch to edit mode.

## Flow 4 - Edit trip

1. User opens an existing trip.
2. User edits stops, leg order, or transport types.
3. User saves changes.
4. Map refreshes from the updated structure.

## Future flow - Map-first creation

1. User starts from an interactive map.
2. User taps or searches to add stops directly on the map.
3. User adjusts order and transport visually.
4. App generates a richer route presentation.
