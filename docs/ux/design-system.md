# Design System

## Color direction

- **Background:** white and off-white
- **Primary accent:** deep sea blue
- **Secondary accent:** sky blue
- **Support accent:** soft slate blue
- **Success:** sea green kept subtle
- **Warning/Error:** warm but restrained

## UI style

- Rounded corners
- Soft elevation
- Clear cards
- Thin dividers
- Blue-forward iconography

## Typography

- Clean sans-serif
- Strong hierarchy
- Large enough body text for mobile readability

## Map treatment

- Keep route lines legible over map tiles
- Use color and icon repetition to show transport context
- Avoid dense overlays in v1
