# Shared AI Rules

## Always honor

- Mobile-first product direction
- Free-first tooling and API choices
- White and blue Mediterranean visual tone
- Single-user MVP
- Form-first trip creation in v1
- Straight-line map legs in v1
- Future map-first editing as an explicit roadmap item

## Engineering behavior

- Reuse documented decisions before inventing new ones.
- Keep code easy to migrate away from provider lock-in.
- Prefer clear types and explicit interfaces.
- Keep docs updated when decisions change.
- Validate changes against the product flows, not only code structure.

## Decision policy

If a detail is not specified, choose the option that best supports:

1. mobile simplicity
2. free tooling
3. future replaceability
4. low user involvement
