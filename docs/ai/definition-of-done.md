# Definition of Done

## Docs work is done when

- relevant product, UX, and architecture docs are updated
- changes do not conflict with non-negotiables
- agent instructions still match the actual stack

## App work is done when

- the flow works on mobile as intended
- state is stored in the correct layer
- validation and error paths are handled clearly
- UI matches the defined design direction

## Automation work is done when

- the MCP server tools are discoverable and documented
- commands are deterministic
- outputs are structured and useful to agents
